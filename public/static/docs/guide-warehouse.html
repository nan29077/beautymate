PARTNERSHIP PROCESS
협업 프로세스 6단계
  1. 사전 미팅 — 창고 규모, 방송 환경, 보유 상품, 희망 방송 빈도를 파악하고 최적의 협업 모델을 설계합니다.
  2. 가맹 파트너 등록 — 셀러브릭스 가맹 창고 파트너로 등록되어 200+ 셀러와 50+ 브랜드에 연결됩니다.
