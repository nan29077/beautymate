## 3. 미수정 잔여 이슈 (우선순위순)

### 🔴 A. 비즈니스 단절 — 결제·예약 플로우 (설계 판단 필요, 최우선)
1. **체크아웃 결제 전면 불가**: `/api/orders` POST는 `reservationDate`/`reservationTime`을 필수로 요구하는데 `CheckoutClient.tsx`·`CartClient.tsx`는 날짜/시간을 아예 보내지 않음(입력 UI도 없음) → 항상 400. PG 3사(스마트로·온기·SeedPay) 서버 구현은 실재하나 주문 생성 단계에서 도달 불가.
2. **신규 예약 플로우(BookingFlow)는 결제 미연결**: `/api/reservations` POST가 항상 `paymentStatus: PENDING`으로 생성하고 결제로 넘기는 코드가 없음 → 영구 미결제.
3. **예약 알림 미연결**: 예약 생성 시 상담사 알림 없음. `notifyReservationConfirmedToCustomer`는 정의만 있고 호출부 0곳 → 확정 알림도 미발송.
4. **두 플로우가 TimeSlot을 공유하지 않음**: `/api/orders`는 슬롯을 점유하지 않고 `maxDailySlots` 카운트만 봄 → 체크아웃 경로 예약은 이중예약 가능.
5. `BookingFlow`가 `?productId`/`?date`/`?time` 쿼리를 무시 — 점집에서 상품을 고르고 넘어와도 처음부터 다시 선택.
6. `/my` 메뉴·MobileNav의 "예약 내역"이 구 `/my/orders`(택배사·운송장 UI 잔존)로 링크, 신규 `/my/reservations`는 사실상 고아. 한쪽으로 통일 필요.
7. `AdminReservationsClient`는 조회 전용 — 관리자가 예약 상태를 변경할 수 없음.
8. 온기(ONGI) 콜백에 서명/IP 검증 없음 — 금액만 맞추면 **무결제 결제완료 위조 가능** (스마트로·SeedPay는 해시 검증 있음). PG사 가이드에 서명이 없다면 최소 IP 허용목록 필요.
9. `api/reservations` POST 동시성: `FOR UPDATE` 잠금 없이 트랜잭션 내 재확인만 → 동시 요청 시 동일 슬롯 경합 여지 (`seller/payouts`의 `$queryRaw ... FOR UPDATE` 패턴 참고).

### 🟠 B. 보안 잔여 (판단 필요 포함)
1. `api/seller/bank-account?sellerId=` — 무인증 계좌 노출. 단, 비로그인 고객에게 입금 계좌를 보여주는 소셜예약 플로우의 설계이기도 함. **공개 유지 여부 결정 필요** (열거 방지가 필요하면 소셜예약 활성 상담사만 응답 등).
2. `api/seller/alimtalk/charge` — 실제 PG 없이 크레딧 즉시 적립(`SIM_` TID). 결제 연동 전 임시 구현으로 보이나, 운영 배포 시 반드시 차단 필요.
3. `api/upload` — 확장자 화이트리스트/크기 제한 없음 → `.html`/`.svg` 저장형 XSS 여지.
4. `api/auth/reset-password` — `mustResetPassword` 미확인: 세션만 있으면 현재 비밀번호 없이 변경 가능.
5. 레거시 role 비교 3곳: `find-id`(BUYER 아이디 찾기 불가), `forgot-password`(BUYER 재설정 차단), `admin/manual-settlements`(레거시 SELLER 수기 정산 불가) — DB raw role에 `normalizeRole` 미적용.
6. `api/orders` 라이브 쿠폰 — 발급 상담사 검증 없음(타 점집 쿠폰 적용 가능). 게임 쿠폰은 검증 있음.
7. `api/live?mode=detail&liveId=` — `isHidden` 필터 없이 채팅 반환. `youtube-sync`/`youtube-chat` 무인증(쿼터 소모). `orders/[id]/delivery` GET 소유권 없음(열거 가능).
8. `api/products/[id]` GET — 상담사가 임의 상품의 타 상담사 판매가 목록 조회 가능.
9. `api/content-posts` POST — `shoppingTags[].productId` 검증 없음.
